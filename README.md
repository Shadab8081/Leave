# Automated Leave Application & Clearance Generator

Fill one Excel sheet → run one command → get every leave document, for every
employee, sorted into folders by sponsor.

## How to run

```
python3 generate_leave_documents.py "Your Input File.xlsx"
```

Optional: choose the output folder name (default is `Leave Documents`):

```
python3 generate_leave_documents.py "Your Input File.xlsx" --outdir "Leave Documents"
```

Documents appear in:

```
Leave Documents/
├── FMCO/EmployeeName_ID/
├── Mehan/EmployeeName_ID/
└── Al Falak/EmployeeName_ID/
```

Plus an `Error_Report.txt` listing any rows that were skipped and why.

## Your Excel input sheet — required columns

| Column header      | Used for |
|---|---|
| EMP ID              | reference only |
| EMP NAME            | employee name |
| JOB TITTLE          | position |
| NATIONALITY         | nationality |
| **SPONSOR ID**      | **sponsor detection** (7…=FMCO, C…=Mehan, EM-…=Al Falak), also printed as Employee ID # — this must be the sponsor code, *not* the Iqama number |
| IQAMA NUMBER        | Iqama # field |
| IQAMA EXP           | Iqama expiry date (Al Falak form only) |
| TYPE OF VACATION    | Annual / Partial / Emergency |
| VAC. START DATE     | leave start date |
| VAC. END DATE       | leave end date |
| NO OF DAYS          | total leave days |
| PROJECT             | project/site |
| PHONE NUMBER        | contact number |
| Hiring date         | joining/hiring date |
| Efective Date       | clearance form effective date |

Optional columns — fill these in and the tool will use them automatically,
leave them out and those fields just print blank:

| Column header | Used for |
|---|---|
| CONTRACT | contract length |
| ENTITLEMENT | leave entitlement |
| EMPLOPYEMENT STATUS | single/married status |
| PAID DAY LEAVE | paid leave days |
| UNPAID DAY LEAVE | unpaid leave days |
| AIR TICKET | who books the ticket |
| EXIT & RE-ENTRY VISA | visa arrangement |
| DESTINATION COUNTRY | travel destination |
| DEPARTURE DATE | departure date |
| ARRIVAL DATE | arrival/return date |
| DEPARTMENT | department |
| LOCATION | site location |

**Important — Sponsor ID vs. Iqama Number:** these are two different numbers.
The Sponsor ID is the short company code (starts with `7`, `C`, or `EM-`) —
it's what tells the tool which sponsor's forms to use. The Iqama Number is
the 10-digit Saudi residency ID (e.g. `2587449311`). If your sheet only has
one of these, add the missing column — the tool needs both.

Keep using these exact headers every time — add or remove employee rows and
re-run the script.

## What gets generated, per sponsor

- **FMCO** → Leave Application Form + Clearance Form
- **Mehan** → Leave Application Form + Clearance Form + Mehan Vacation Request Format
- **Al Falak** → Leave Application Form + Clearance Form + Al Falak Leave & Visa Request Form

## Validation

Before generating anything, every row is checked for: employee name, valid
Sponsor ID format, recognized leave type, and valid start/end dates. Rows
with problems are skipped and listed (with row number and reason) in
`Error_Report.txt` — no incomplete documents are ever produced.

## Known limitations / things worth a quick manual check

- **Al Falak's PDF form isn't a fillable PDF** — the tool overlays typed text
  at fixed positions on top of the original scan/print, so alignment is very
  close but not pixel-perfect. Worth a quick glance the first few times.
- That same Al Falak form has no checkbox for **Partial Leave** (only End of
  Contract / Annual / Emergency / Personal exist on the official template),
  so for Partial Leave the tool prints a small "(Partial)" note near the
  checkbox row instead of guessing which box to tick.
- Fields not present in your input sheet (Iqama number, Contract length,
  Entitlement days, ticket/visa details, family members, department/location
  for some sponsors) are left blank on the generated forms rather than
  showing another employee's old sample data. Add matching columns any time
  and the script will start filling them automatically.
- The Witness Undertaking Form (found in your Partial/Emergency Leave
  folders) is not generated by this version — let me know if you'd like that
  added.
